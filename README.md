# أكسير (Aksir)

محرر جداول بيانات خفيف الوزن مبني بلغة C++ وQt6، يعمل على Windows 11 (64-bit).

## البناء

يتم بناء التطبيق تلقائيًا على GitHub Actions عند كل push إلى فرع `main`.
نزّل الملف المضغوط من قسم **Actions > آخر workflow ناجح > Artifacts**.

## المكونات

- C++17
- Qt 6.8 (Widgets)
- CMake 3.16+
- MSVC 2022 (x64)
